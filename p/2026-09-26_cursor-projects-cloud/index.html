Cursor Projects

What it is

  • The coordinator: Plans and delegates — it never writes code itself
  • The subagents: Do the actual coding and testing, in parallel
  • Where it runs: On its own computer in the cloud
  • Launched: September 10, 2026, in beta for all users

6x

more pull requests merged

  • Cursor: users who primarily work through Projects merge 6x as many PRs; new users merge 30% more.

Coordinator, then subagents

How it works

  • You describe the work — In chat, to the coordinator
  • It plans and delegates — Creates and runs subagents for you, as many as the work needs
  • It never blocks — Since it delegates instead of coding, it stays responsive to you
  • Keeps shared context — Subagents add research and what they learn about your codebase

Closing your laptop doesn't stop it

Why the cloud matters

  • Runs on: Its own computer in the cloud
  • Scale: More agents in parallel than your laptop could support
  • Local testing: The coordinator spins up a local agent when it needs your machine

Work that outlives one chat

Best for

  • A feature with several PRs — Not a single quick fix
  • A migration — Something that would take you weeks alone
  • A job for while you're away — Kick it off, check back later

From the sidebar

How to start one

  • Open Projects — Click New Project in the left-hand nav
  • Name it — Pick an icon and a name
  • Pick your setup — Choose the workspace repository and coordinator model
  • Describe the work — Tell the coordinator what you want built — it takes it from there
