Five switches, what each one does

THE PANEL

  • CLAUDE.md — Instructions Claude reads automatically at the start of every session
  • Slash commands — Your own reusable /commands, saved as a file
  • Permission modes — How much Claude does before it stops and asks
  • Hooks — Shell commands that fire on Claude Code's own events
  • Subagents — Helpers with their own tools and their own context window

CLAUDE.md: it never forgets your project

SWITCH 1 · MEMORY

  • Where it lives — A markdown file in your project's root folder
  • Turn it on — Run /init — Claude scans the codebase and drafts one
  • What goes in it — Build commands, conventions, repeated instructions
  • Loads every time — Reads automatically at the start of every session
01

Custom slash commands

Add `$ARGUMENTS` inside the file to pass in details, like `/deploy staging`.

Save a markdown file at .claude/commands/deploy.md with your steps written out, and Claude turns the filename into /deploy — one word instead of retyping the whole routine.

Permission modes: how much it asks first

SWITCH 3 · CONTROL

  • default: Asks before every file edit and most shell commands
  • plan: Only reads and proposes a plan, changes nothing yet
  • acceptEdits: Auto-accepts file edits, still asks before risky commands
  • bypassPermissions: Skips prompts entirely — for sandboxes, not daily use

Hooks: your own code on Claude's events

SWITCH 4 · AUTOMATION

  • What it is — A shell command that runs automatically on a Claude Code event
  • Where it lives — The hooks key inside .claude/settings.json
  • One example — Run your test suite automatically after every file edit
  • Check what's set — Type /hooks inside Claude Code to see every hook that's live

Subagents: a helper with its own window

SWITCH 5 · DELEGATION

  • Where they live — One markdown file per subagent, inside .claude/agents/
  • What's inside — A name, a description, and which tools it's allowed to use
  • Why it helps — Big searches and logs stay out of your main conversation
  • How to call one — Claude picks one automatically, or you name it directly
