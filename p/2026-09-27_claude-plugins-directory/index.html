From GitHub repo to live plugin

How developers publish

  • Submit — Point to a remote MCP server, or a bundle of MCP servers and skills on GitHub
  • Get scanned — Anthropic checks and safety-scans the submission right away
  • Review it — See review status, feedback, and the safety-scan results
  • Publish — Once approved, the developer chooses when it goes live
