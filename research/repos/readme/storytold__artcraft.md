ArtCraft is the IDE for interactive AI image and video creation. Compose in 2D, stage scenes in 3D, and choose the models that fit your work. Turn prompting into *crafting* with visual tools for precise, repeatable results.

## Show, Don't Tell: Advanced Crafting Features

Artists need control over composition, character identity, and camera placement. Build the scene before you generate it. Click any preview to view it at full size.

| Feature | Preview |
| ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Image to Location** Place virtual actors in a consistent environment and plan multiple shots in the same room. | |
| **3D Image Compositing** Layer backdrops, foregrounds, and props in 3D to build compositions with depth. | |
| **2D Image Compositing** Compose a scene with image layers, background removal, and drawing tools. | |
| **Image to 3D Mesh** Turn an image into a 3D object you can position, rotate, and frame precisely. | |
| **Character Posing** Pose characters and set your camera before generating the final shot. | |
| **Scene Blocking with Kitbashing** Combine 3D asset kits to control camera angles, object placement, and depth. | |
| **Character Identity Transfer** Use a posed mannequin to guide the placement and pose of your character. | |
| **Background Removal** Isolate subjects to use as props, layers, or backdrops in 2D and 3D scenes. | |
| **Mixed Asset Crafting** Combine image cutouts, worlds, and 3D meshes in one scene. | |

More previews are coming for scene blocking, canvas editing, and scene relighting.

## Quick and Easy Prompting

Start with a prompt when you want to explore an idea quickly, then use the canvas and scene tools to refine it.

| Feature | Preview |
| ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Text to Image** Explore ideas across a wide range of image models with a text prompt. | |
| **Prompted Image Editing** Describe changes to an image with models such as Nano Banana Pro and GPT Image. | |
| **Canvas Image Editing** Use drawing, masks, and inpainting to guide exactly where an image changes. | |
| **Image to Video** Animate an image with your choice of video models and generation controls. | |

More previews are coming for image inpainting and image ingredients.
